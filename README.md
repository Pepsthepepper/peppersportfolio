# Pepper’s portfolio

This is a static portfolio published to GitHub Pages from the `site/` directory.

The Pages workflow deploys on pushes to `main` and can also be started manually from the Actions tab. In repository settings, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected.

The source portfolio’s playable work samples were not included in this static copy, so the work section intentionally avoids placeholder thumbnails and embeds.
